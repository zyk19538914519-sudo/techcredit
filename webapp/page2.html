① 项目团队协同（多 Agent 共享同一项目知识库）
项目 = 团队 × 企业。项目负责人创建项目后把邀请码发给队友；团队成员各自注册 FateBuddy 账号、各领各的 MCP 接入码，不同的 Agent 即可协同调用同一项目的底稿知识库—— 平台公共数据全员可见，项目内上传底稿仅成员可见，跨项目严格隔离。 每个项目自带专属记忆服务＋专属知识库（一个项目一个记忆服务器、一个知识库）： 记忆经 project_memory_add / project_memory_search 按项目服务级隔离沉淀，底稿入 techcredit-prj-* 专属库与平台公共库合并检索，队友的 Agent 随时协同。
