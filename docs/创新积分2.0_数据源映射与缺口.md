# 创新积分制2.0 × techcredit 数据源映射与缺口

依据：科技部《"创新积分制"工作指引（2.0版）》（2025-10，全国试行版）附件1/2/3。
体系：创新投入50 + 创新产出30 + 创新发展20 + 创新影响加分30；权重按成长阶段（初创0-5年/成长5-10年/稳定10+年）与8大技术领域差异化。
结论先行：**专利类指标已覆盖；财务类（研发费用/营收/净利）和加分类（项目/奖励/标准/资质/融资/排名）是主要缺口；其中研发费用、技术合同成交额、银行贷款对非上市企业无公开源，必须走"自报+代理指标+缺失值动态调权"。**

## 二、权重适配所需的基础字段（已有）

- 成长阶段：成立日期 → 天眼查工商画像 ✅（0-5/5-10/10+年）
- 8大技术领域：天眼查国标行业代码 + 智慧芽 IPC → 自建"行业/IPC→8领域"映射表；或 UI 让客户经理选赛道 ✅输入已有
- 分级分档：A≥85 / B70-85 / C60-70 / D<60（加分后总分130）→ 计算层实现，无需新源

## 三、需要新增的 API / 数据源（按优先级）

P0（决定核心分能否算出）
1. 巨潮资讯网 cninfo（免费爬）+ 东方财富妙想 MX（Key已有）：上市/挂牌的研发费用、研发人员数、主营收入、营收增速、净利润、所有者权益、募资公告。覆盖指标1/2/3/7/8/9/11。
2. 国家企业信用信息公示系统 年报（免费爬）：非上市可选公示的营收/净利润/资产/参保；抓不到就标缺失。
3. 全国标准信息公共服务平台（免费）：标准起草单位 → 指标10。

P1（加分项与知识产权口径完整）
4. 科技/资质公示爬虫：科技部+省科技厅立项与奖励名单、高新/科技型中小/专精特新/小巨人名单 → 指标10/12。
5. 软著/布图/植物新品种：中国版权保护中心公告、国知局布图公告、农业农村部植物新品种公告（免费爬）；或天眼查 VIP 一次拿全 → 指标5。
6. 中登网动产融资统一登记公示（免费查询）：应收账款质押/转让登记含担保金额 → 指标11 贷款代理。
7. IT桔子/烯牛 API（付费）：天使/VC 事件与金额 → 指标11。

P2（代理与排名）
8. 招聘结构：天眼查招聘(VIP)或招聘平台爬 → 指标3 研发人员代理。
9. 行业榜单：协会/工信部榜单爬 + 天眼查 ranking_list(VIP)；市场机构报告付费可选 → 指标12。
10. 技术合同登记公示（部分省科技厅）+ 智慧芽转让/许可备案 → 指标6 代理。

## 四、必须承认的"无公开源"集合（设计缺失值动态调权）

非上市企业的：研发费用金额、研发费用占比、技术合同成交额、银行贷款额。
税务/科技合同登记/银行征信均不对外提供 API。处理方式（与宏观规划一致）：
- 优先企业自报（UI 录入）+ 佐证材料上传；
- 无自报时用代理指标（发明人计数、中标金额汇总、中登网担保额、专利转让记录）并降权；
- 触发规划中的"缺失值动态调权"，把权重重新分配到可采集指标，避免硬凑分。

## 五、对现有网关的改动建议

- store.py KIND 增加：FIN 财务 / STD 标准 / CER 资质 / AWD 项目奖励 / FUND 融资 / RANK 排名 / IPX 软著布图新品种。
- gateway.py 增加：CninfoClient / MxClient(妙想) / GsxtClient(年报) / StdClient(标准) / GovNoticeCrawler(科技/资质公示) / ZhongdengClient / ItjuziClient。
- 计算层新增"指标→字段→Source_ID"绑定表，确保每个得分可溯源（呼应校验熔断）。

### 最终确认无公开 API（只能爬/网页/自报/代理）
1. **研发人员数**（非上市）：无 API；上市走年报(cninfo/MX)，非上市自报+招聘结构(企查查718)代理。
2. **技术合同成交额**（企业级）：全国技术合同管理系统 ctmht.chinatorch.org.cn 需企业登录；仅地方开放平台有区域汇总API；企业级自报+专利转让/许可(智慧芽)代理。
3. **科技计划项目立项**：国家科技管理信息系统 service.most.gov.cn 需登录；立项公示网页爬。
4. **科技奖励**：科技部政务平台奖励查询+奖励办 nosta.gov.cn 公示目录，网页爬。
5. **标准起草单位**：std.samr.gov.cn 高级检索网页，无公开API，爬。
6. **非上市研发费用/营收/净利**：工商年报可选公示（天眼查825/企查查213 若公示可得），否则自报+调权。
7. **银行贷款余额**：征信不开放；用动产抵押/股权出质担保额(企查查747/751)代理。

### 结论
12 指标中除上述 7 项硬缺口外，其余均已找到可用 API（商业按次 / 地方开放平台免费 / CNIPR 注册）。
推荐补齐顺序：CNIPR 注册(布图+新品种) → 企查查套餐或天眼查充值(参保/资质/榜单/担保/年报) → 浙江/无锡/北京开放平台 key(省级资质免费) → 剩余 5 项写爬虫 + 自报调权。
